TIRJET - REACT NATIVE SCREEN STRUCTURE
======================================

Purpose
-------
This is a screen-by-screen map of the current Next.js client to help rebuild
the app with React Native. The route names below are the existing web routes.
Suggested React Native names are examples; you can use Expo Router or React
Navigation and adjust the file layout to match.

The server/ folder is the backend and is not part of the React Native screens.
The current app/api/ directory contains web API routes, not page screens.

4. SHARED APP FEATURES TO REBUILD
---------------------------------

- App navigation: replace web links and the shared Header/footer with native
  navigation, headers, and (if useful) bottom tabs.
- Authentication: sign-in and session handling; check which OAuth providers
  are supported by the backend and native configuration.
- Cart: shared cart state, item quantities, totals, and checkout navigation.
- Checkout: shipping form, order review, payment method, and success state.
- Profile: account details and saved/favorite products.
- API access: keep using the existing server endpoints where suitable; move
  web fetch logic into reusable React Native services.
- Feedback: replace browser toasts/dialogs with native alerts or a native toast
  component.
- Media: use React Native image components and verify remote image URLs.
- Design: adapt the current web layouts to mobile-sized screens rather than
  trying to reuse HTML, CSS, or browser-only components.


5. MIGRATION NOTES
------------------

- Dynamic route parts in brackets are identifiers: [id], [type], [slug].
  Pass them as route parameters in React Native navigation.
- The category route uses a catch-all slug ([...slug]); decide how to represent
  multi-part category paths in the native route parameters.
- Existing web routes use mixed capitalization. Use consistent native screen
  names, and preserve the route/API behavior while migrating.
- A practical first milestone is Home, Shop, ProductDetails, Cart, Login, and
  Profile, then add checkout and the informational sections.
